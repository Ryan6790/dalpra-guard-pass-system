# 🥋 SISTEMA DALPRA - PASSAGEM DE GUARDA

## Desvendando o Jogo de Passagem de Guarda de Tainan Dalpra

Um site educacional completo sobre o sistema de pressure passing do campeão Tainan Dalpra. Aprenda as técnicas, estratégias e detalhes que fazem a diferença no Jiu-Jitsu.

## 📋 Conteúdo

### 1. **5 Pilares do Sistema Dalpra**
   - Postura Baixa
   - Controle de Distância
   - Quebra de Grips
   - Pressão Contínua
   - Mobilidade

### 2. **Como Começar a Passagem**
   - Posicionamento Inicial
   - Controle Dominante

### 3. **3 Técnicas Principais**
   - **Knee Cut Pass** - A base do sistema
   - **Over-Under Pass** - Quando knee cut não funciona
   - **Torreira Pass** - Mobilidade horizontal

### 4. **Conceito de Variação Rápida**
   - O ciclo contínuo de Tainan Dalpra
   - Como variar quando bloqueado

### 5. **Selando a Passagem**
   - Controle de Lapela
   - Head Control
   - Quadril Pesado

### 6. **5 Erros Críticos a Evitar**
   - Postura Alta
   - Dar espaço para os pés
   - Comprometer em uma técnica
   - Recuar com resistência
   - Soltar a cabeça

### 7. **Fluxograma Completo**
   - Mapa visual de todas as técnicas
   - Decisões e variações

## 🚀 Como Usar

### Opção 1: Hospedar no GitHub Pages (Recomendado)

1. **Clone ou fork este repositório:**
   ```bash
   git clone https://github.com/Ryan6790/dalpra-guard-pass-system.git
   cd dalpra-guard-pass-system
   ```

2. **Vá para as configurações do repositório:**
   - GitHub → Settings → Pages

3. **Em "Source", selecione:**
   - Branch: `main`
   - Folder: `/ (root)`

4. **Clique em Save**

5. **Acesse seu site em:**
   ```
   https://ryan6790.github.io/dalpra-guard-pass-system
   ```

### Opção 2: Abrir Localmente

Simplesmente abra o arquivo `index.html` em seu navegador:

```bash
# Windows
start index.html

# Mac
open index.html

# Linux
xdg-open index.html
```

## 🔧 Personalização

### Mudar Cores

Edite as variáveis CSS em `styles.css`:

```css
:root {
    --primary-color: #1a1a1a;        /* Fundo principal */
    --secondary-color: #2d2d2d;      /* Fundo secundário */
    --accent-color: #d4a574;         /* Cor de destaque (ouro) */
    --accent-alt: #c41e3a;           /* Cor alternativa (vermelho) */
    --text-color: #e0e0e0;           /* Texto claro */
    --text-dark: #b0b0b0;            /* Texto escuro */
}
```
