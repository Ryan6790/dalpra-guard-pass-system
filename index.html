5 Pilares do Sistema Dalpra

A fundação de todo o sistema de passagem

1

Postura Baixa

Quadril baixo + base larga = impossível ser desequilibrado. A estabilidade é a chave.

2

Controle de Distância

Mãos dominam joelhos e linha da cintura. Zero espaço para o adversário reagir.

3

Quebra de Grips

Desconectar pés, dominar calcanhares e joelhos para desestabilizar as pernas.

4

Pressão Contínua

Torso no chão, cabeça próxima ao osso do quadril. Impedir recomposição da guarda.

5

Mobilidade

Reposicionamento rápido, trocar de direção. Forçar reação do guardeiro.

Como Começar a Passagem

Os primeiros passos críticos

1

Posicionamento Inicial

  • Você em base (hands in base)
  • Adversário em guarda fechada
  • Quebrar a guarda: empurrar um pé para baixo
  • Abrir espaço: pressionar joelho para longe
→
2

Controle Dominante

  • Mão direita: segura a lapela/colarinho
  • Mão esquerda: controla o joelho esquerdo
  • Pressão: levar peso para o joelho dele
  • Objetivo: impedir reaproximação dos pés

3 Técnicas Principais

O arsenal de passagem de Tainan Dalpra

1. KNEE CUT PASS - A Base do Sistema

⭐⭐⭐ Fundamental

A Anatomia:

  1. Posição de Entrada
    • Um joelho no chão próximo às costelas
    • Outro pé em base (do lado que vai passar)
  2. Controle Superior
    • Mão no pescoço/lapela do adversário
    • Pressionar a cabeça para baixo
    • Impedir que ele vire para sua guarda
  3. O Corte de Joelho
    • Joelho corta horizontalmente pela cintura
    • Empurra a coxa do adversário para fora
    • Torso segue pressionando no abdome
  4. Completar a Passagem
    • Joelho passa pela cintura
    • Outro pé segue em base firme
    • Pressão até side control

⚠️ Detalhe Crítico Dalpra:

  • Ele CHEIRA o quadril
  • Postura sempre reta
  • Nunca recua quando encontra resistência

2. OVER-UNDER PASS - Quando Knee Cut Não Funciona

⭐⭐⭐⭐ Intermediária

Setup Completo:

  1. Posição Base
    • Dois joelhos no chão ou um joelho + um pé em base
  2. Os Braços Trabalham
    • Braço A (OVER): por cima da coxa esquerda
    • Braço B (UNDER): por baixo da perna direita
    • Puxar as pernas juntas
  3. Ombro no Game
    • Ombro entra no abdome
    • Pressão diagonal do ombro para fora
    • Força o adversário a girar
  4. Progresso para Lateral
    • Manter braços juntos
    • Quadril acompanha
    • Avançar até side control

💡 Vantagem Dalpra:

  • Se knee cut é bloqueado
  • Ele já tem o over-under iniciado
  • Transição imperceptível

3. TORREIRA PASS - Mobilidade Horizontal

⭐⭐⭐⭐⭐ Avançada

Quando Usar:

  • Quando ambas técnicas anteriores encontram resistência
  • Adversário muito defensivo

Execução:

  1. Empurrar Lateralmente
    • Mãos empurram ambas as pernas para UM lado
    • Ex: empurra joelhos para a esquerda
  2. Você Se Move pelo Lado Oposto
    • Enquanto empurra para esquerda
    • Você passa pelo lado direito
    • Corpo segue a reação do adversário
  3. Controlando o Quadril
    • Mão no quadril dele
    • Impede que ele volte o quadril
    • Ombro pressiona a cintura
  4. Finalizando
    • Você já está na lateral
    • Side control estabelecido

🎯 Princípio Dalpra:

  • Não é bruto força
  • Usa reação do adversário
  • Aproveita movimento dele contra ele

Selando a Passagem

O detalhe que Tainan faz para dominar

1. Controle de Lapela (Com Kimono)

  • Segura forte a lapela
  • Impede reposição para guarda
  • Estabiliza a lateral

2. Head Control

  • Mão na cabeça dele
  • Pressionando para baixo
  • Tira a visão do adversário
  • Impede que ele gire

3. Quadril Pesado

  • Seu quadril pressiona o dele
  • Zero espaço para escapar
  • Peso distribuído strategicamente

🏁 Resultado Final:

Side Control DOMINANTE - Adversário imobilizado, pronto para montar ou transicionar para scarf hold.

5 Erros Que Bloqueiam Sua Passagem

O que NÃO fazer

❌

Erro 1: Postura Alta

Problema: Fácil ser desequilibrado

✅ Solução: Quadril sempre baixo

❌

Erro 2: Dar Espaço para os Pés

Problema: Guardeiro recompõe e você volta ao zero

✅ Solução: Mãos SEMPRE controlando joelhos

❌

Erro 3: Comprometer em Uma Técnica

Problema: Adversário adapta e bloqueia

✅ Solução: Treinar as 3 técnicas + variações

❌

Erro 4: Recuar com Resistência

Problema: Perde momentum

✅ Solução: Pressionar MAIS + variar ângulo

❌

Erro 5: Soltar a Cabeça

Problema: Adversário escapa pelo movimento

✅ Solução: Head control até ter side control 100%
